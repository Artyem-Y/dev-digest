# MCP SDD Specifications

This directory contains SDD specifications for changes owned only by the MCP
package. Start with the [MCP README](../../README.md) for current behavior.

Specifications define proposed tool behavior, input and output contracts,
trust boundaries, compatibility, failure behavior, edge cases, and acceptance
criteria. They do not contain implementation steps or code.

If a feature affects MCP and another DevDigest module, place its specification
in the [cross-module SDD directory](../../../docs/specs/README.md).

Use `YYYY-MM-DD-<kebab-feature-name>.md` file names and the corresponding
`SPEC-YYYY-MM-DD-<kebab-feature-name>` identifier.
