# Reviewer Core SDD Specifications

This directory contains SDD specifications for changes owned only by the
reviewer-core package. Start with the [reviewer-core README](../../README.md)
for current behavior.

Specifications define proposed behavior, input and output contracts, trust
boundaries, error behavior, grounding requirements, edge cases, and acceptance
criteria. They do not contain implementation steps or code.

If a feature affects reviewer-core and any other DevDigest module, place its
specification in the [cross-module SDD directory](../../../docs/specs/README.md).

Use `YYYY-MM-DD-<kebab-feature-name>.md` file names and the corresponding
`SPEC-YYYY-MM-DD-<kebab-feature-name>` identifier.
