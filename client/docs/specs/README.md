# Client SDD Specifications

This directory contains SDD specifications for changes owned only by the client
package. Start with the [client README](../../README.md) for current behavior.

Specifications define the proposed behavior, UX states, accessibility
requirements, contracts, edge cases, and acceptance criteria. They do not
contain implementation steps or code.

If a feature affects the client and any other DevDigest module, place its
specification in the [cross-module SDD directory](../../../docs/specs/README.md).

Use `YYYY-MM-DD-<kebab-feature-name>.md` file names and the corresponding
`SPEC-YYYY-MM-DD-<kebab-feature-name>` identifier.
